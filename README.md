A complete web-based **Library Management System** developed using PHP, MySQL, HTML, CSS, and JavaScript. This system automates day-to-day library operations including book management, member registration, book issue/return tracking, and real-time availability monitoring with a unique per-copy LIB numbering system.

---

## 🎯 Features

### 👑 Admin Functions
- **Dashboard** - Real-time statistics overview
- **Book Management** - Add/Edit/Delete books with automatic LIB number generation
- **Member Management** - Register/Delete library members
- **Issue Books** - Issue specific book copies (by LIB number) to members
- **Return Books** - Process returns with automatic availability update
- **Transaction History** - View all issue/return records with search & filter
- **Overdue Detection** - Automatic highlighting of books overdue >14 days

### 👤 Member Functions
- **Browse Books** - View all books with availability status
- **My Issued Books** - Personal borrowing history
- **Overdue Alerts** - Visual warnings for overdue books
- **Profile Information** - View personal account details

### 🔐 Security Features
- Role-based access control (Admin/Member)
- PHP session management
- SQL injection prevention
- Secure login validation

### 🏷️ Unique LIB Number System
- Every physical copy gets a unique identifier (LIB001, LIB002, ...)
- Sequential automatic generation
- Track exactly which copy is issued to which member
